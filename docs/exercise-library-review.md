## Video verification scope

77 of 100 guides have metadata-verified external references, including the original eight. Public YouTube search results were used only to discover candidate IDs. Selected IDs were requested from YouTube’s public oEmbed endpoint to confirm exact titles and channel attribution, then the published watch-page descriptions were reviewed for exercise/equipment agreement. No search-result links are stored as demonstrations. Each included reference records the review date (2026-10-18) and verification notes in the typed data.

This is metadata and publisher-description verification, not full playback or independent coaching certification. Full video playback, regional availability, age restrictions, future availability and every technique cue were not verified. The 23 uncertain variants below have no video field. Human review of playback remains appropriate before approving the links. The kettlebell-deadlift publisher description contains an erroneous exercise heading, while its kettlebell lifting steps and title agree; this is explicitly recorded in its notes.

All video descriptions in FormFuel are original short introductions. No creator descriptions, transcripts, thumbnails or logos are reproduced. Only external watch links are provided; no video media is hosted, embedded or downloaded. No ownership, endorsement or permission to reproduce the videos is asserted.

## Guides without verified references

These are verification gaps, not claims that suitable videos do not exist. Their written guidance and related links remain available.

- **One-Arm Dumbbell Row:** Candidate uses knee-on-bench support; the existing guide uses a staggered standing stance.
- **Band Row:** Candidates were seated or did not establish the standing bilateral setup.
- **Glute Bridge:** Candidate metadata did not establish the floor-supported two-leg variation.
- **Dead Bug:** The NASM candidate starts with limbs extended; an alternative did not establish the guide’s tabletop start.
- **Chest-Supported Dumbbell Row:** Candidate description did not establish the incline-bench setup.
- **Inverted Row:** Candidate description did not establish a securely fixed bar rather than suspension handles.
- **Dumbbell Pullover:** Candidate description did not establish full-length bench support and one dumbbell.
- **Band Pull-Apart:** Candidate description did not establish the band position and movement setup.
- **Step-Up:** Could not establish the unloaded step-up without an additional knee drive.
- **Single-Leg Romanian Deadlift:** Candidate describes lowering a weight; this guide teaches an unloaded hinge.
- **Band Lateral Walk:** The descriptive NASM candidate puts the band at the ankles; this guide uses above-knee placement.
- **Standing Dumbbell Shoulder Press:** Candidate metadata did not establish standing rather than seated support.
- **Reverse Pec Deck Fly:** Candidate description did not establish the chest-supported machine setup.
- **Dumbbell Front Raise:** Candidate description was promotional and did not establish the form variation.
- **Band External Rotation:** Candidate description did not establish the elbow-at-side position.
- **Dumbbell Scaption:** Candidate description did not establish the standing thumbs-up setup.
- **Assisted Triceps Dip:** Exact machine setup and suitable educational source were not established confidently enough.
- **Pallof Press:** Could not establish standing cable resistance rather than a band or different stance.
- **Hanging Knee Raise:** Candidate description did not establish bent knees and an unsupported overhead hang.
- **Suitcase Carry:** Could not establish one dumbbell rather than a different implement.
- **Turkish Get-Up:** Could not establish the full kettlebell sequence rather than a partial or different-implement variation.
- **Brisk Walking:** Candidate description did not establish a walking-technique demonstration.
- **Stationary Cycling:** Candidate description did not establish the intended bike setup and pedaling instruction.
